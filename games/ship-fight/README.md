# Ship Fight

An ad-free naval battle game against the computer, part of the Arcade. Three AI levels, a Daily Hunt that is the same for every player, levels, achievements and unlockable seas, markers and win effects. No accounts, no ads, no network requests.

- Build: `python3 build.py` (Python 3, no dependencies) → `dist/`
- Tests: `node tests/run.js` (Node 18+), plus `node tests/layout.js` with Playwright and Chrome
- Handing it to Arcade: see `HANDOFF.md`
